## 적용 방법

`assets/duckhoo-theme.css` 를 통째로 복사해
**WP 관리자 → 사용자 지정하기 → 추가 CSS** 에 붙여넣는다.
(Code Snippets 플러그인이 이미 활성이므로 CSS 스니펫으로 넣어도 된다.)

되돌리기는 그 CSS 를 지우는 것으로 끝난다. DB 는 건드리지 않는다.

## 색

밝은 색을 면에 채우고 **그 위에 검정을 얹는다.** 흰 글자를 쓰려고 색을
어둡게 낮추면 화면이 칙칙해진다 — 이건 취향이 아니라 산수 문제다.

```
--dh-accent       #38BDF8   채움 (버튼, 배지, 선택 상태)
--dh-accent-ink   #111111   그 채움 위 글자. 흰색 아님        8.81:1
--dh-accent-deep  #1565C0   흰 배경 위 색 글자 · 포커스 링    5.75:1
--dh-accent-soft  #E8F5FE   아주 옅은 면
--dh-ink          #111111   본문                            18.88:1
--dh-ink-2        #4E565F   보조                             7.45:1
--dh-ink-3        #616870   캡션                             5.64:1
```

포커스 링에 `--dh-accent` 를 쓰지 않는다. 흰 배경에서 2.14:1 이라 안 보인다.
모든 값은 흰 카드와 `#F5F5F7` **양쪽에서** AA 를 넘긴다. 한쪽만 보고 정하면
캡션이 바탕 위에서 미달한다.

## 지켜야 할 규칙

- 모바일 우선. `min-width` 미디어쿼리만 쓴다
- 본문 16px 아래로 내리지 않는다 — iOS 가 입력 시 화면을 확대한다
- 터치 타깃 44px, 주요 CTA 48px
- 한글에 `word-break: break-all` 을 쓰지 않는다 (`keep-all`), 음수 자간도 금지
- `100vh` 대신 `100dvh`
- 반투명·`backdrop-filter` 금지 — 카드가 수십 개 깔리는 목록에서 스크롤이 끊긴다
- 병당 가격이 고객의 비교 지표다. 총액보다 크게 쓴다
- 주문 상태는 **색만으로 구분하게 두지 않는다.** 항상 한글 라벨과 함께

## 절대 건드리지 말 것

법적 의무이거나 매출에 직결된다. 스타일만 위에 얹는다.

| 기능 | 플러그인 |
|---|---|
| 휴대폰 본인확인 (19세 미만 판매금지) | `dreamsecurity-mobile-auth` |
| 주문 상태 (입금전→배송완료) | `keyple-order-status` |
| 입금 자동확인 (안드로이드 헬퍼 앱) | `keyple-bank-auto-confirm` |
| 고객관리 (등급·적립금) | `keyple-customer` |
| 쿠폰 · 송장 · 정산 · 게시판 | 나머지 keyple, kboard |

구체적으로:
- **폼 필드의 `name` / `id` 를 바꾸지 않는다.** 입금 자동매칭이 이름으로 걸려
  있어서, 여기 손대면 모든 주문이 `확인필요` 로 떨어진다
- 성인인증 단계를 건너뛰거나 숨기지 않는다
- 결제·장바구니의 데이터 경로에 개입하지 않는다
- `pgall-for-woocommerce`(심플페이)가 비활성인 것은 의도된 상태다. 켜지 않는다

## 결제

카드결제를 쓰지 않는다. 무통장입금 전용이다.
**입금자명이 주문자명과 일치해야 자동 입금확인이 된다.** 다르면 `확인필요` 로
넘어가 사람이 손으로 처리한다. 그래서 주문서에서 입금자명 입력을 약하게 만드는
디자인은 곧 운영 비용이다. 결제 단계뿐 아니라 앞단에서도 한 번 보여준다.

## 아직 안 된 것

- 상품 사진이 데모에서 자리표시자다. 실제 이미지는 1:1 정사각(1254×1254)
- `[dh_coverflow]` 숏코드가 죽어 있다 — `duckhoo-front` 가 없는
  `dist/dh-front.js` 를 찾는다. 대체 번들은 `design/coverflow.js`
- `duckhoo-front` CSS 에 `!important` 가 270개. 테마와 싸우는 중이라
  테마 업데이트에 취약하다
- **회원탈퇴와 주문취소가 동작하지 않는다.** 원인 미확인.
  유력한 가설: 키플이 추가한 커스텀 주문상태(`입금전`·`확인필요`)가 WooCommerce 의
  취소 가능 상태 목록(`woocommerce_valid_order_statuses_for_cancel`)에 없으면
  취소 버튼 자체가 렌더링되지 않는다. 거기부터 확인할 것
