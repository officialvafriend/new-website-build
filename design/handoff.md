**홈 (위에서 아래로)**

2. 헤더 — 로고 · 넓은 검색창(데스크톱) · 장바구니 알약(담으면 "N병") · 아바타. 모바일은 검색 아이콘
3. 히어로 2장 — 흰 카드 "신상 입고"(상품 1개) + 하늘색 그라데이션 "9월 특가 무니코틴 최대 10%"
4. **오늘의 특가** 회색 패널 — 9/30 23:59 KST 마감 카운트다운(초 단위) + 가로 스크롤 카드
5. **지금 고르세요** — 가운데 큰 제목 + 필터 알약(브랜드 · 니코틴 · 맛) + 4열 그리드 12개 + 더 보기
6. **브랜드 공식 스토어** — 인증 배지 · ★평점 · 종수 · 판매수 · 2×2 썸네일, 3장
7. 이번 달 볼 것 — 커버플로우 (`design/coverflow.js`, 바닐라 JS)
8. 검은 배너 "9월엔 병당 가격으로 고르세요"
9. 검은 푸터 — 소개 · 카카오톡 채널 · 링크 4열(상품 · 브랜드 · 안내 · 고객지원) · 법적 고지. **모든 화면에** 붙는다

**상품 카드** — 흰 카드, 이미지는 안에서 한 번 더 둥글게, 왼쪽 위 아이브로(신상 · 9월 특가 · 재구매 1위 · 품절),
오른쪽 위 찜 하트, 이름(2줄), ★4.8 · 668개 판매, 정가 취소선 + 가격 + "원 · 병당"

**상품 상세** — 이미지 + 썸네일 4개 → 브랜드 · 이름 · 한 줄 설명 → 가격(병당) → 구성 선택(카드형 옵션, 병당가 병기)
→ 니코틴 칩 → 합계 → 스티키 구매바(장바구니 · 바로 구매) → 탭(상품 설명 · 제품 정보 표 · 리뷰 · 배송·교환 FAQ)

**모바일** — 아래 탭바 5개(홈 · 상품 · 장바구니 · 주문내역 · 마이). 문서는 스크롤하지 않고 본문 영역만 스크롤한다.
그래야 주소창이 접혔다 펴져도 탭바가 안 움직인다. 큰 제목이 올라가면 헤더에 작은 제목이 뜬다.

**운영 규칙이 화면에 들어가 있다** — 주문서에서 입금자명 ≠ 주문자명이면 `확인필요` · 주문취소는 `입금전`만 ·
회원탈퇴는 미배송 주문이나 적립금이 있으면 막힘 · 회원가입은 본인확인이 1단계

## 적용 방법 — 순서대로

1. **스테이징에 GitHub Deployments 연결** (WP.com 대시보드 → 배포 → 저장소 연결). 브랜치
   `claude/ui-ux-design-refresh-p5czcx`, 대상 `/wp-content/plugins/new-website-build`, 자동 배포 켜기.
   `.deployignore` 덕에 올라가는 건 플러그인 본체 · `includes/` · `assets/` 뿐이다
2. 플러그인 **액상덕후 리디자인** 활성화 → 확인할 것 세 가지:
   - 마이페이지 주문내역에서 `입금전` 주문에 **취소 버튼**이 뜨는가
   - `/membership-cancel/` 에 **탈퇴 폼**이 뜨는가 (원래 `/` 한 글자짜리 빈 페이지였다)
   - 미배송 주문이 있는 계정에서 탈퇴가 **막히는가**
3. `assets/duckhoo-theme.css` 를 통째로 **사용자 지정하기 → 추가 CSS** 에 붙여넣기 (Code Snippets 도 됨).
   되돌리기는 그 CSS 를 지우는 것으로 끝난다
4. 홈 구성은 테마 프론트페이지/블록에서 데모 순서대로 잡는다. 실제 상품 사진은 1:1 정사각(1254×1254)
5. 프로덕션은 **동기화 버튼을 쓰지 않는다** (DB 까지 덮어써 주문·회원·적립금이 사라진다).
   프로덕션에도 GitHub Deployments 를 따로 연결해 이 플러그인 폴더만 배포한다

## 글자 · 색 · 아이콘

- **Pretendard** (테마가 이미 쓴다). 데모는 CSP 때문에 파일 안에 심었지만 실제 사이트는 링크로 쓰면 된다
- 캡션 최소 13px, 본문 15–16px, 큰 제목 34px/900. **11–12px 은 쓰지 않는다** —
  안드로이드 기본 한글 폰트는 중간 굵기가 없어 얇고 흐리게 나온다

## 지켜야 할 규칙

- 모바일 우선. `min-width` 미디어쿼리만
- 폼 글자 16px 아래로 내리지 않는다 (iOS 확대)
- 터치 타깃 44px, 주요 CTA 48px
- 한글에 `word-break: break-all` 금지 (`keep-all`), 음수 자간 금지
- `100vh` 대신 `100dvh`. 아래 고정 바는 `fixed` 가 아니라 흐름 안에 둔다
- 반투명 · `backdrop-filter` 금지 — 카드가 수십 개인 목록에서 스크롤이 끊긴다
- 병당 가격이 고객의 비교 지표다. 총액보다 크게
- 주문 상태는 색만으로 구분하지 않는다. 항상 한글 라벨과 함께
- 칩·필터는 진짜 `<button>`/`<select>` (aria-pressed, aria-label). 이모지를 아이콘으로 쓰지 않는다

## 결제

무통장입금 전용. **입금자명이 주문자명과 일치해야 자동 입금확인.** 다르면 `확인필요` 로 사람이 처리한다.
주문서에서 입금자명 입력을 약하게 만드는 디자인은 곧 운영 비용이다. 앞단에서도 한 번 안내한다.

## 라이브 버그 두 개 — 고쳐서 플러그인에 넣어 뒀다

**주문취소** — 이 사이트의 입금 전 주문은 `on-hold`("결제 확인 중", 293건)다. "입금전"·"확인필요" 상태는
실제로 없다. WooCommerce 는 `pending`·`failed` 에만 취소 링크를 그려서 버튼이 없었다.
`woocommerce_valid_order_statuses_for_cancel` 에 **`on-hold`** 를 더했다. 입금확인(`payment-confirmed`) 이후는 안 연다.

**회원탈퇴** — 테마 마이페이지의 "회원탈퇴 신청" 버튼이 부르는 `admin-ajax` 액션 `wd_membership_cancel` 이
서버에 없다 (버튼만 있고 뒤가 없다). `/membership-cancel/` 을 플러그인이 통째로 그리고 자체 처리로 바꿨다.
`includes/membership-cancel.php`: 계정은 남기고 로그인을 끊고 개인정보만 지운다(거래기록 5년 보존).
비밀번호 재입력 + 동의 + 논스. 미배송 주문 · 남은 적립금이 있으면 막는다.
**적립금 저장 키를 아직 모른다** — 메타 이름으로 찾고, 못 찾으면 그걸로는 안 막는다. 키를 알면:
`add_filter('duckhoo_member_points', fn($v,$id)=>(float)get_user_meta($id,'<키>',true),10,2);`

둘 다 워드프레스 없이 스텁으로만 검증했다 (`php design/php-tests/run.php`, 22개). **실제 사이트에서 돌려본 적은 없다.**
