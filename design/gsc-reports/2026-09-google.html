1. 한 장 요약

이렇게 했고
  • 9/10 상품 184종에 검색 결과용 설명을 붙이고 브랜드 페이지 30장을 열었습니다 (그 전에는 사진뿐이라 구글이 읽을 글자가 없었습니다).
  • 9/15 「타격감」 분류를 새로 만들었고, 9/21 노보 15종의 제목 · 설명과 노보 분류 제목을 바꿨습니다.
  • 9/28 회원 전용 페이지 12장을 검색에서 빼고(색인 제외), 지운 상품 「크래프트」의 옛 주소를 입호흡 분류로 보내고, 전 상품 가격표 페이지를 열었습니다.
이런 결과가 있었고
  • 8월보다 클릭 +45% · 노출 +32% (413 → 598 · 2,471 → 3,257). 이름 검색을 뺀 새 손님 클릭은 18 → 60 으로 3.3배, 그중 노보가 0 → 32 입니다 (2쪽).
  • 9월 안에서는 노출이 늘었는데 클릭은 그대로입니다. 하루 노출 97번(첫 주) → 131번(셋째 주), 클릭은 하루 21~25번 그대로. 새 페이지가 검색 결과에 더 자주 보이기 시작했지만 5~8위라 아직 눌리지 않습니다.
  • 이름 검색이 여전히 절반 넘습니다. 「액상덕후」 339 클릭 = 57%. 우리를 이미 아는 손님입니다. 새 손님이 들어오는 길은 「노보액상」(27 클릭) 하나가 뚜렷합니다.
  • 노보는 먹었습니다. 노보 분류 페이지가 9월 23 → 35 클릭, 노보 낱말 7개 합쳐 32 클릭 · 6.6위.
