# 9월 자동 할인(10만원↑ 10,000원) 끄는 법

## 왜 플러그인만으로는 안 되나

할인이 테마에 **두 번** 적혀 있다.

**(가) 돈을 깎는 쪽** — `wp-content/themes/키플_액상덕후/functions.php:10668`

```php
add_action( 'woocommerce_cart_calculate_fees', function( $cart ) {
    $total = Σ( 가격 × 수량 ) − 쿠폰할인;
    if ( $total >= 100000 ) $discount = 10000;
    $cart->add_fee( '🎁 금액 자동 할인', -$discount, false );
}, 20 );
```

**(나) 결제 화면에 그리는 쪽** — `woocommerce/checkout/form-checkout.php:145`

```php
// 표시 안정화: fee 목록 대신 직접 구간 계산 (부과 로직과 동일 기준)
$wd_tier_base = Σ( 가격 × 수량 ) − 쿠폰할인;
if ( $wd_tier_base >= 100000 ) { $wd_auto_fee_discount = 10000; }
elseif ( $wd_tier_base >= 80000 ) { $wd_auto_fee_discount = 5000; }
...
```

장바구니 화면은 fee 를 합산하지만(`functions.php:1940`), **결제 화면은 fee 를 무시하고
스스로 다시 계산한다.** 그래서 (가)만 꺼도 결제 화면은 10,000원을 계속 빼고,
실제 주문 금액과 어긋나 총액이 무너진다. 프로덕션에서 확인했다 — 노보 장바구니에서
총 주문금액이 0원이 됐다.

## 고칠 곳 — 딱 한 군데

`wp-content/themes/키플_액상덕후/woocommerce/checkout/form-checkout.php` 의
**145줄부터 시작하는 「표시 안정화」 블록을 지운다** (또는 주석 처리).

```php
// ↓↓↓ 이 블록을 지운다 (145줄 ~ 구간 계산이 끝나는 줄까지) ↓↓↓
// 표시 안정화: fee 목록 대신 직접 구간 계산 (부과 로직과 동일 기준)
$wd_tier_base = 0;
foreach ( WC()->cart->get_cart() as $wd_ti ) { … }
$wd_tier_base -= (float) WC()->cart->get_discount_total();
if ( $wd_tier_base >= 100000 ) { $wd_auto_fee_discount = 10000; }
elseif ( $wd_tier_base >= 80000 ) { $wd_auto_fee_discount = 5000; }
elseif ( $wd_tier_base >= 50000 ) { $wd_auto_fee_discount = 3000; }
// ↑↑↑ 여기까지 ↑↑↑
```

위쪽 134~143줄의 fee 합산은 **그대로 둔다.** 그러면 결제 화면도 장바구니처럼
fee 를 보게 되어 두 화면의 값이 갈릴 이유가 사라진다.

## 그 다음 — 아무것도 안 하셔도 됩니다

블록을 지우시면 **그 순간 할인이 저절로 꺼집니다.** 배포도, 눌러야 할 버튼도 없습니다.

플러그인이 매번 그 파일을 읽어 블록이 아직 있는지 봅니다. 있으면 손대지 않고
(할인은 지금처럼 그대로), 없어지면 그때 비로소 fee 를 붙이는 함수를 훅에서 뗍니다.
장바구니 안내 문구("10만원 이상 …")도 같이 사라집니다.

그 동안에는 관리자 화면(상거래 · 도구 · 플러그인)에 **왜 아직 안 꺼졌는지** 알림이
뜹니다. 알림이 사라지면 꺼진 것입니다.

되살리고 싶으시면: `add_filter( 'duckhoo_kill_auto_discount', '__return_false' );`

**노보만 빼는 것도 같은 자리에서 됩니다** — 블록을 지운 뒤에는 우리가 fee 를 다시
지으면 되므로, 노보를 뺀 금액으로 계산하도록 만들어 드릴 수 있습니다.

## 테마를 못 고치신다면

키플에 이렇게 요청하시면 됩니다:

> `woocommerce/checkout/form-checkout.php` 의 「표시 안정화: fee 목록 대신 직접 구간
> 계산」 블록 때문에, 금액대별 자동 할인을 끄거나 조건을 바꾸면 결제 화면 금액이
> 장바구니와 어긋납니다. 그 블록을 지우고 위의 fee 합산 결과를 그대로 쓰도록
> 해 주세요. (장바구니 화면 `functions.php:1940` 은 이미 그렇게 되어 있습니다.)
