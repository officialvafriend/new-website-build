# 9월 자동 할인(10만원↑ 10,000원) — 껐습니다

**2026-09-09 부터 duck-hoo.com 에서 이 할인은 적용되지 않습니다.** 사장님이 하실 일은
없습니다. 테마 파일은 한 글자도 고치지 않았습니다.

## 어디에 있던 할인인가

테마에 **두 번** 적혀 있었습니다.

**(가) 돈을 깎는 쪽** — `themes/키플_액상덕후/functions.php:10668`

```php
add_action( 'woocommerce_cart_calculate_fees', function( $cart ) {
    if ( 상품금액 >= 100000 ) $discount = 10000;
    $cart->add_fee( '🎁 금액 자동 할인', -$discount, false );
}, 20 );
```

**(나) 결제 화면에 그리는 쪽** — `woocommerce/checkout/form-checkout.php:145`

이쪽은 (가)가 붙인 fee 를 **보지 않고 같은 계산을 한 번 더** 합니다
(`$wd_auto_fee_discount`). 그래서 (가)만 꺼도 결제 화면은 10,000원을 계속 빼서
실제 주문 금액과 어긋났습니다 — 노보 장바구니에서 **총 주문금액 0원**이 나왔던 이유입니다.

## 테마를 안 고치고 끈 방법

워드커머스는 화면을 그릴 때마다 **「이 템플릿은 어느 파일을 쓸까」를 플러그인에 묻습니다**
(`wc_get_template`). 플러그인은 그때 테마 파일 대신 **사본**의 경로를 돌려줍니다.

사본은 테마 파일을 **읽어서** `$wd_auto_fee_discount = 10000;` 의 **숫자만 0 으로**
바꾼 것입니다. 테마 파일은 열지도, 쓰지도 않습니다.

- 바꾸는 것이 숫자 하나뿐이라 **문법이 깨질 수 없습니다**
- 사본 이름에 원본 파일의 수정시각·크기가 들어가 있어, 나중에 테마가 바뀌면 **자동으로
  다시 만듭니다**
- 숫자를 한 군데도 못 찾으면 **아무것도 하지 않고 할인을 그대로 둡니다** (그때는 관리자
  화면에 알림이 뜹니다). 모르면 건드리지 않는 쪽입니다
- 사본은 `wp-content/uploads/duckhoo-tpl/` 에 있습니다. 지워도 다음 방문 때 다시 생깁니다

## 확인한 것 (프로덕션, 실제 계정으로)

| 장바구니 | 상품금액 | 총 주문금액 |
|---|---|---|
| 노보 낱병 10병 — 전에 0원이 나던 장바구니 | 135,000 | **135,000** ✅ |
| 펠릭스 2개 | 178,000 (정가와의 차이 22,000은 그대로 표시) | **178,000** ✅ |
| 노보 10병 + 펠릭스 1개 | 224,000 | **224,000** ✅ |
| 낱병 2병 (10만원 미만) | 27,000 | 29,500 (배송비 2,500) ✅ |

장바구니의 「10만원 이상 1만원 할인」 **안내 문구도 같이 사라집니다.** 없는 혜택을 보고
담은 손님이 결제 화면에서 배신당하지 않도록 함께 껐습니다.

## 되돌리려면

둘 중 하나면 됩니다.

- 플러그인(액상덕후 리디자인) 비활성화 — 즉시 원래대로
- 코드 한 줄: `add_filter( 'duckhoo_auto_discount_mode', fn() => 'off' );`

라이브에서 미리 확인만 하고 싶을 때는 `'preview'` 로 두면 됩니다 — 쿠키
`dhr_disc_off` 를 가진 사람에게만 꺼지고 손님들은 그대로 봅니다.
