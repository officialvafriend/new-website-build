  • 페이지는 여섯 장 — 홈 · 매장 안내 · 각인 서비스 · 메뉴판 · 브랜드 · SNS. 네이버는 그중 다섯 장을 색인했습니다.
  • 검색엔진이 읽을 글자가 페이지마다 충분합니다(홈 7만 자 · 매장 3만 자). 사진뿐인 사이트가 아닙니다.
이런 결과가 있고
  • 대구 전체 검색어에서는 첫 화면 위쪽입니다 — 「대구전자담배」 6위 · 「대구전자담배매장」 2위 · 「대구전자담배액상」 5위 · 「대구일회용전자담배」 7위.
  • 지점 검색어에서는 첫 화면 아래쪽입니다 — 상인동 · 두류동 · 현풍 전자담배 셋은 웹문서 15위 안에 홈페이지가 없고, 동성로 · 수성구는 12위입니다. 반월당 4위 · 동대구 11위 · 율하 11위.
  • 이름 검색 「베이프렌드」에서 홈페이지가 웹문서 4위입니다. 앞자리는 유튜브 채널과 다른 전자담배 매장 사이트 두 곳입니다. 상호를 검색한 사람이 홈페이지를 바로 못 찾습니다.
걸리는 것
  • 매장 8곳이 한 페이지 안의 격자라 지점마다 검색될 주소 · 제목이 없습니다. 「율하전자담배」를 쳐도 나오는 것은 홈(11위)뿐입니다.
  • 주소가 두 벌입니다. 네이버가 아는 주소는 옛 stores.html 꼴이고 사이트맵은 새 /stores 꼴인데, 어느 쪽이 대표인지 적는 표시(canonical)가 한 장도 없습니다. 신호가 갈립니다.
  • 메뉴판 · 매장 안내 · SNS 세 장은 대표 제목(h1)이 없고 메뉴판은 설명도 없습니다. 홈의 대표 제목은 영문 「VAFRIEND」 한 낱말입니다.
앞으로 이렇게 (10월)
  • ① 지점별 페이지 8장. 「율하 전자담배 베이프렌드 율하점 — 주소 · 영업시간 · 지도」처럼 지점 이름이 제목에 있는 페이지 하나씩. 지점 검색어 첫 화면 진입이 목표입니다.
  • ② 주소 정리. 페이지마다 대표 주소 표시를 넣고, 옛 .html 주소는 영구 이동(301)으로 새 주소에 붙인 뒤 사이트맵을 다시 제출합니다.
  • ③ 제목 · 설명 채우기. 홈 대표 제목을 「대구 전자담배 전문 매장 베이프렌드」로, 메뉴판 · 매장 · SNS 세 장에 대표 제목과 설명을 넣습니다.
  • 10월 말 다시 재는 숫자: 지점 검색어 첫 화면 5개 → 7개, 「베이프렌드」 웹문서 4위 → 1위, 「대구전자담배」 6위 → 3위 안.

3. 걸리는 것 · 10월 계획

걸리는 것 넷

무엇숫자왜 문제인가
지점별 페이지가 없다지점 검색어 9개 중 첫 화면 5개매장 8곳이 「매장 안내」 한 장의 격자에 들어 있어, 「상인동전자담배」로 검색하는 사람에게 보여 줄 페이지가 없습니다. 홈페이지는 대구 전체 검색어만 받고 지점 손님은 놓칩니다.
주소 두 벌 · 대표 주소 표시 없음6쪽 전부네이버는 stores.html 을, 사이트맵은 /stores 를 가리킵니다. 같은 페이지가 두 주소로 보이면 점수가 나뉘고, 자동 이동이 임시(307)라 네이버가 옛 주소를 계속 씁니다.
이름 검색에서 4위「베이프렌드」 웹문서 4위홈의 대표 제목이 「VAFRIEND」 영문뿐이고 한글 상호가 대표 제목에 없습니다. 유튜브 채널 · 다른 매장 사이트가 앞에 섭니다.
제목 · 설명 빈칸대표 제목 없는 페이지 3 · 설명 없는 페이지 1메뉴판 · 매장 안내 · SNS 는 검색엔진이 「무슨 페이지」인지 첫 줄에서 알 수 없습니다.

10월에 할 일 셋

  • ① 지점별 페이지 8장. 주소 /stores/yulha 처럼 지점마다 한 장. 제목 「율하 전자담배 베이프렌드 율하점 | 주소 · 영업시간 · 주차」, 본문에 오시는 길 · 취급 제품 · 사진, 지점 사업체 구조화 데이터. 매장 안내 페이지는 8장으로 가는 목록으로 남깁니다.
  • ② 주소 정리. 여섯 장 전부에 대표 주소 표시(canonical)를 넣고, .html 주소는 영구 이동(301)으로 바꾼 뒤 사이트맵을 다시 제출합니다. 각인 광고 페이지는 사이트맵 · 검색 결과에서 빼 달라고 서치어드바이저에 요청합니다.
  • ③ 제목 · 설명 채우기. 홈 대표 제목 「대구 전자담배 전문 매장 베이프렌드」, 메뉴판에 설명, 매장 안내 · SNS 에 대표 제목. 다섯 장에도 사업체 구조화 데이터를 넣습니다.

4. 낱말 풀이 · 어떻게 쟀나

낱말 풀이

웹문서 탭
네이버 검색 결과에서 「웹문서」를 눌렀을 때 나오는 목록. 홈페이지 순위는 전부 여기 기준입니다.
대표 주소 표시 (canonical)
같은 페이지가 여러 주소로 열릴 때 「이 주소가 진짜」라고 검색엔진에 알리는 한 줄.
영구 이동 (301) · 임시 이동 (307)
옛 주소를 새 주소로 보낼 때, 영구 이동이어야 검색엔진이 새 주소로 갈아탑니다. 임시 이동은 옛 주소를 그대로 둡니다.
구조화 데이터
회사 이름 · 주소 · 영업시간을 검색엔진이 읽는 형식으로 적어 둔 것. 지도 · 매장 정보 노출에 쓰입니다.
