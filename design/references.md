# 레퍼런스 분석

사람이 준 이미지 5장(패션 커머스 3, nitec 오디오 1, 스크롤 페이지 1)에서
공통으로 반복되는 것들. 이 프로젝트가 가져갈 어휘.

## 상품 카드

- **카드마다 배경색이 다르다.** 분홍·노랑·보라 같은 연한 톤을 상품 뒤에 깔고,
  상품은 누끼로 얹는다. 흰 카드에 사진 하나 넣는 흔한 방식과 다른 지점.
  액상덕후는 상품 이미지가 1:1 정사각이므로 그대로 적용 가능하다.
- **좌상단에 작은 알약 라벨** (Women / Chocolates / Shoe).
  액상덕후에서는 니코틴 함량(0mg / 0.98mg / 9.8mg)이 여기 온다.
- **하단에 가격 + 원형 장바구니 버튼**을 카드 안에 겹쳐 놓는다.
  카드 전체가 상세로 가는 링크이고, 원형 버튼만 바로 담기.
- 모서리 반경이 크다 (20~24px).

## 헤드라인

- 한 줄 안에서 **굵기를 섞는다** — "Sustainably **Stylish.** Naturally You".
  Pretendard 는 100~900 을 다 갖고 있으므로 400/900 대비로 같은 효과를 낼 수 있다.
- 알약 모양 CTA. 검정 채움, 흰 글자.

## 섹션 구성

- 브랜드 로고 스트립 (거래 브랜드 나열) — 액상덕후는 취급 브랜드 9개가 있으니 그대로 쓴다.
- **아이콘 3~4개짜리 안내 스트립**을 연한 색 면 위에 올린다
  (Payment Method / Return policy / Customer Support).
  액상덕후는 계좌이체 안내 · 배송 · 교환반품 · 카톡 문의가 여기 온다.
  홈에 계좌 안내 블록을 크게 넣는 것보다 이 형태가 낫다.
- 상품 그리드 위에 **필터 탭**을 둔다 (전체 / 신상 / 인기 …).
- 리뷰를 카드로 가로 배치.

## 상품 상세 (wink 레퍼런스)

- 왼쪽 큰 이미지 + 오른쪽 썸네일 3~4장 그리드.
- **검정 바에 가격과 구매 버튼**을 묶어 한 덩어리로.
- 색상·사이즈를 원형/알약 스와치로. 액상덕후는 맛·니코틴 함량이 여기 온다.

## 안 가져올 것

- 반투명·블러 (사람이 명시적으로 빼기로 함)
- 모델 사진 중심 구성 — 액상덕호는 상품컷이 AI 생성 정물이라 인물 레이아웃이 안 맞는다
