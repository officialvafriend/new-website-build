# 레퍼런스 분석

사람이 준 이미지 5장(패션 커머스 3, nitec 오디오 1, 스크롤 페이지 1)에서
공통으로 반복되는 것들. 이 프로젝트가 가져갈 어휘.

## 상품 카드

- **카드마다 배경색이 다르다.** 분홍·노랑·보라 같은 연한 톤을 상품 뒤에 깔고,
  상품은 누끼로 얹는다. 흰 카드에 사진 하나 넣는 흔한 방식과 다른 지점.
  액상덕후는 상품 이미지가 1:1 정사각이므로 그대로 적용 가능하다.
- **좌상단에 작은 알약 라벨** (Women / Chocolates / Shoe).
  액상덕후에서는 니코틴 함량(0mg / 0.98mg / 9.8mg)이 여기 온다.
- **하단에 가격 + 원형 장바구니 버튼**을 카드 안에 겹쳐 놓는다.
  카드 전체가 상세로 가는 링크이고, 원형 버튼만 바로 담기.
- 모서리 반경이 크다 (20~24px).

## 헤드라인

- 한 줄 안에서 **굵기를 섞는다** — "Sustainably **Stylish.** Naturally You".
  Pretendard 는 100~900 을 다 갖고 있으므로 400/900 대비로 같은 효과를 낼 수 있다.
- 알약 모양 CTA. 검정 채움, 흰 글자.

## 섹션 구성

- 브랜드 로고 스트립 (거래 브랜드 나열) — 액상덕후는 취급 브랜드 9개가 있으니 그대로 쓴다.
- **아이콘 3~4개짜리 안내 스트립**을 연한 색 면 위에 올린다
  (Payment Method / Return policy / Customer Support).
  액상덕후는 계좌이체 안내 · 배송 · 교환반품 · 카톡 문의가 여기 온다.
  홈에 계좌 안내 블록을 크게 넣는 것보다 이 형태가 낫다.
- 상품 그리드 위에 **필터 탭**을 둔다 (전체 / 신상 / 인기 …).
- 리뷰를 카드로 가로 배치.

## 상품 상세 (wink 레퍼런스)

- 왼쪽 큰 이미지 + 오른쪽 썸네일 3~4장 그리드.
- **검정 바에 가격과 구매 버튼**을 묶어 한 덩어리로.
- 색상·사이즈를 원형/알약 스와치로. 액상덕후는 맛·니코틴 함량이 여기 온다.

## 안 가져올 것

- 반투명·블러 (사람이 명시적으로 빼기로 함)
- 모델 사진 중심 구성 — 액상덕호는 상품컷이 AI 생성 정물이라 인물 레이아웃이 안 맞는다

# 사람이 준 HTML 두 개 (2026-09-02)

저장된 페이지 두 개를 직접 뜯어본 결과. "이대로만 해다오, 구매버튼과 드로어
작동방식은 크런틴처럼" 이라는 지시에 대한 근거.

## Apple Store 온라인 (KR) — 화면 구조

- 카테고리마다 **`살펴보기` / `쇼핑하기` 두 링크를 한 쌍**으로 붙인다.
  Mac / iPad / iPhone / Watch / Vision / AirPods 가 전부 같은 형식.
  액상덕후에서는 브랜드나 니코틴 함량이 그 자리에 온다.
- 각 섹션 본문은 **가로 스크롤 카드 줄** (`rf-cards-scroller`, `rf-ccard`).
  카드 63개가 이 구조로 깔린다. 모바일에서 세로 길이를 잡아먹지 않는 방식.
- 카드는 `rf-ccard-img-full-wrapper` — 이미지가 카드 안을 꽉 채운다.
- 흰 바탕, 큰 여백, 카드 배경만 연한 색.

## 크런틴 (cruntin.com, Cafe24) — 구매 동작

핵심은 **옵션이 드롭다운이 아니라 버튼 타일**이라는 점이다.

```html
<ul option_style="button" class="ec-product-button" required="true">
  <li option_value="[3+1]스타터팩 총 4박스"
      title="[3+1]스타터팩 총 4박스 (+68,500원)">
```

- 타일 하나에 **구성 이름 + 추가 금액**이 같이 붙는다.
- 구성이 박스 수로 올라간다: 4박스 / 6박스 / 7박스 / 9박스.
  많이 살수록 개당 싸지는 구조를 옵션 자체가 보여준다.
  **액상덕후의 병 수와 정확히 같은 구조다.**
- 구매는 버튼 두 개가 나란히:
  `장바구니`(btnNormal, 보조) + `바로 구매`(btnSubmit, 주). 둘 다 아이콘 포함.

이 프로젝트에 옮길 때 더할 것: 타일에 **병당 가격**도 같이 쓴다.
크런틴에는 없지만 액상덕후는 병당가가 비교 지표이므로,
구성을 고르는 순간 병당가가 얼마로 떨어지는지 그 자리에서 보여야 한다.

WooCommerce 에서의 대응: 이 역할을 PPOM 필드가 한다. `duckhoo-front` 가
이미 PPOM 을 STEP 카드로 감싸고 있으므로 구조를 새로 만들 필요는 없고,
원본 필드를 `.dhx-src` 로 감춘 채 타일 UI 를 얹는 기존 방식을 그대로 쓴다.
