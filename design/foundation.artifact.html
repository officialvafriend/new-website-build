확정

모바일에서 실제로 깨지는 것들

기반 CSS 에 이미 반영해 둔 규칙입니다. 전부 국내 모바일 환경에서 반복적으로 문제가 되는 항목입니다.

  • ✓100vh 대신 100dvh — 모바일 브라우저 주소창 때문에 100vh 는 화면보다 큽니다.
  • ✓word-break: keep-all — 한글에서 break-all 을 쓰면 어절 중간이 끊깁니다.
  • ✓viewport 메타 태그 — width=device-width, initial-scale=1.
  • ✓표는 자기 안에서 스크롤 — 페이지 전체가 가로로 밀리지 않게 합니다.
  • ✓고정폭 숫자 — 가격 · 통계처럼 세로로 정렬되는 숫자에 적용합니다.
  • ✓키보드 포커스 표시 — :focus-visible 에 항상 보이는 외곽선.
  • ✓모션 최소화 존중 — prefers-reduced-motion 에서 애니메이션을 끕니다.
  • ✓다크 모드 — 토큰만 재정의. 시스템 설정과 명시적 선택 양쪽 대응.
