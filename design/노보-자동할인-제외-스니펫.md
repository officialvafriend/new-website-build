# 노보를 금액대별 자동 할인에서 빼는 법 (Code Snippets)

9월 이벤트: **10만원 이상 10,000원 자동 할인**, **노보는 제외**.

할인을 붙이는 코드는 워드프레스 관리자 → **Snippets** 안에 있습니다. 목록에서
`금액 자동 할인` 또는 `cart_calculate_fees` 가 들어간 PHP 스니펫을 찾으세요.

## 왜 플러그인에서 못 하고 스니펫에서 해야 하나

플러그인에서 그 할인 줄을 **뒤늦게 걷어내 봤습니다.** 줄은 실제로 사라지는데,
테마 결제 요약의 `쿠폰할인 -10,000원` 은 그대로 남습니다 — 테마가 그 금액을 수수료
줄과 **별개로** 들고 있습니다. 그래서 총 주문금액이 0원이 됩니다.

기준에 못 미치는 장바구니(10만원 아래)는 멀쩡히 그려집니다. 그러니 「할인 줄이 없는
것」이 문제가 아니라 **뒤늦게 빼는 것**이 문제입니다. 애초에 안 만들면 됩니다.

## 붙일 코드

스니펫 맨 위에 이 함수를 넣습니다.

```php
/**
 * 자동 할인 기준 금액 — 노보 액상은 빼고 센다.
 */
function dhr_discount_base() {
    $base = 0;
    if ( ! function_exists( 'WC' ) || ! WC()->cart ) {
        return 0;
    }
    foreach ( WC()->cart->get_cart() as $item ) {
        $p = isset( $item['data'] ) ? $item['data'] : null;
        if ( ! $p instanceof WC_Product ) {
            continue;
        }
        // 노보는 이벤트 제외 대상 — 기준 금액에 넣지 않는다.
        if ( has_term( 'novo-liquid', 'product_cat', $p->get_id() ) ) {
            continue;
        }
        $base += (float) $p->get_price() * (int) $item['quantity'];
    }
    return $base;
}
```

그리고 스니펫에서 **기준 금액을 읽는 줄**을 바꿉니다. 보통 이렇게 생겼습니다:

```php
$total = WC()->cart->get_subtotal();          // ← 이런 줄을
$total = WC()->cart->cart_contents_total;     // ← 또는 이런 줄을

$total = dhr_discount_base();                 // ← 이걸로 바꾼다
```

그러면 노보만 담은 장바구니는 기준 금액이 0원이라 할인이 **애초에 안 붙고**,
노보 + 다른 상품이면 다른 상품 금액만으로 10만원을 넘겼는지 봅니다.

## 확인

| 장바구니 | 할인 |
|---|---|
| 노보만 135,000원 | 없음 |
| 노보 135,000 + 다른 상품 89,000 | 없음 (기준 89,000원) |
| 노보 135,000 + 다른 상품 178,000 | 10,000원 |
| 노보 없이 178,000원 | 10,000원 |

고치신 뒤 알려 주시면 제가 로그인해서 네 경우를 다 재 보겠습니다.
