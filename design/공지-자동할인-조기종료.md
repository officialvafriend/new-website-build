# 공지사항 초안 — 자동 할인 조기 종료

`/notice/` 는 **kboard 게시판**(페이지 499)이다. 워드프레스 글이 아니라서 플러그인이
대신 올릴 수 없다 — 관리자로 로그인해 게시판에서 직접 쓴다.

상단 검은 띠는 한 줄이라 「왜」를 담지 못한다. 그 자리를 이 글이 받는다.

---

## 제목

```
10만원 이상 1만원 자동 할인 이벤트 조기 종료 안내
```

## 본문

```
안녕하세요, 액상덕후입니다.

9월 진행 중이던 「10만원 이상 구매 시 10,000원 자동 할인」 이벤트가
9월 9일부로 조기 종료되었습니다.

- 종료일: 2026년 9월 9일
- 종료 대상: 10만원 이상 구매 시 10,000원 자동 할인
- 종료 시점 이전에 접수된 주문에는 할인이 그대로 적용되어 있습니다.
  이미 받으신 할인이 취소되거나 금액이 다시 청구되는 일은 없습니다.

아래 혜택은 그대로 이어집니다.

- 30,000원 이상 무료배송
- 회원가입 시 8,800원 적립금 즉시 지급
- 노보 10+1 묶음 이벤트 (물량 관계로 한 분당 하루 한 세트)

예정보다 이르게 종료하게 되어 죄송합니다.
문의는 카카오톡 오픈채팅방 또는 1:1 문의 게시판으로 남겨 주시면
확인 후 답변드리겠습니다.

감사합니다.
```

## 쓸 때 주의

- **종료 사유를 지어내지 않았다.** 넣고 싶으시면 「예정보다 이르게…」 앞에 한 줄
  더하면 된다 (예: `준비한 물량이 조기에 소진되어` · `내부 사정으로`).
  사유를 적을 자신이 없으면 안 적는 편이 낫다 — 틀린 사유가 더 큰 문의를 부른다
- **날짜 경계를 「9월 8일까지」로 쓰지 않았다.** 9월 9일 낮에 껐으므로 그날 오전
  주문에도 할인이 붙어 있다. 「종료 시점 이전」이 사실에 맞다
- **이미 받은 할인은 취소되지 않는다**는 문장이 문의를 가장 많이 줄인다. 손님이
  제일 먼저 걱정하는 것이 그것이다
- 상단 띠 문구와 **같은 이름**을 쓴다 — 「10만원 이상 1만원 자동 할인」.
  띠에서 보고 들어온 사람이 같은 글인지 바로 알아야 한다
